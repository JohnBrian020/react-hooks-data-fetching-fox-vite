# 🐶 DogFinder

DogFinder is a React application that fetches and displays random dog
images using the Dog CEO API.

## Features

- Loads a random dog image when the application starts
- Allows users to request another random dog
- Displays a loading message while fetching
- Uses React `useEffect` for the initial API request
- Uses an `onClick` event to fetch additional images

## Technologies Used

- React
- JavaScript
- Vite
- Dog CEO
